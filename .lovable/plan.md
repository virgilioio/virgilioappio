

# Redesign Candidate Profile PDF Download

## Current State

The PDF generator (`src/utils/candidatePdfGenerator.ts`) produces a basic profile with: logo, candidate name, job title, location, salary, LinkedIn URL, skills, and profile summary. It's missing all the enrichment data (seniority, functional area, current role/company, years of experience) and the relational data (work experience, education, certifications) that are already displayed in the UI.

The download is triggered directly with no user options — no dialog, no choice about contact details.

## What We'll Build

### 1. Download Options Dialog

A new `CandidateProfileDownloadDialog` component that appears when the user clicks "Download". It provides:
- A toggle/checkbox: **"Include contact details"** (phone, email, LinkedIn URL, location)
- A "Download PDF" button that triggers generation with the selected options

This is a simple, clean dialog — not a complex form.

### 2. Enhanced PDF Generator

Restructure `generateCandidatePdf` to accept additional data and options:

```text
┌──────────────────────────────────────────┐
│ [Logo]                                    │
│ ─────────────────────────────────────────│
│ CANDIDATE NAME                   (H1)    │
│ Current Job Title at Company     (H3)    │
│ Seniority · Functional Area · X yrs exp  │
│                                          │
│ [Contact Details — if opted in]          │
│ Email · Phone · Location · LinkedIn      │
│                                          │
│ SKILLS                           (H2)    │
│ [pill] [pill] [pill] [pill]              │
│                                          │
│ PROFILE SUMMARY                  (H2)    │
│ Text content...                          │
│                                          │
│ WORK EXPERIENCE                  (H2)    │
│ ▸ Job Title at Company                   │
│   Jan 2022 – Present · 2 yrs            │
│   Description text...                    │
│                                          │
│ ▸ Previous Role at Company               │
│   Mar 2019 – Dec 2021 · 2 yrs 9 mos     │
│                                          │
│ EDUCATION                        (H2)    │
│ ▸ Degree in Field of Study               │
│   Institution · 2018                     │
│                                          │
│ CERTIFICATIONS                   (H2)    │
│ ▸ Certification Name                     │
│   Issuing Org · 2020                     │
│                                          │
│ ───────────────────────────────────────  │
│ Generated by Virgilio - Page X of Y      │
└──────────────────────────────────────────┘
```

### 3. Data Flow

The callers (CandidateProfileSheet, IndependentCandidateProfileSheet, CandidateProfile page) already fetch `workExperience`, `education`, and `certifications` from Supabase. The dialog will receive these as props and pass them to the generator.
